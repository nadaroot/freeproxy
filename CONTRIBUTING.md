# Contributing to Smart Proxy Pool

Contributions and suggestions are welcome.

### Development Steps

1. Fork and clone the repository.
2. Install dependencies: `pip install -r requirements.txt`.
3. Check code formatting and syntax: `python -m py_compile main.py smart_proxy_pool/*.py`.
4. Submit a clear Pull Request.

### Guidelines

- Keep the proxy validation fast and non-blocking.
- Maintain test coverage for public proxy sources.
